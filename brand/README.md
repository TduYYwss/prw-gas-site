# PRW Gas Services: logo files

A sharp, redrawn version of the PRW logo. The shapes were traced from the flyer and the colours sampled from it, so it's the same logo, just clean at any size. The lettering is Montserrat, matched to the flyer for weight and spacing.

| File | Use it for |
|---|---|
| `prw-mark.svg` | The flame on its own, any size. Best for printers and sign makers. |
| `prw-logo-stacked.svg` | Flame above the name, as on the flyer. Flyers, van panels, posters. |
| `prw-logo-horizontal.svg` | Flame beside the name. Website, email signature, letterheads, invoices. |
| `prw-mark-2048.png`, `prw-mark-512.png` | Flame on a transparent background, for apps that don't take SVG. |
| `prw-logo-stacked-2000.png` | Stacked logo, transparent background. |
| `prw-logo-horizontal-2400.png` | Horizontal logo, transparent background. |
| `prw-profile-picture-1080.png` | Square on white. Facebook, Google and WhatsApp Business profile pictures. |

## Colours
- Ring: `#205182`
- Red flame: shades from `#e72029` to `#9d1216`
- Blue flame: shades from `#1d5d94` to `#0ea1dd`
- **P** `#1d4898` · **R** `#de3e47` · rest of the name `#121212` · tagline `#3d3d3d`

## Notes
- Send printers the **SVG** files. They scale to any size without going blurry.
- If whoever designed the original logo still has the master file, that's the true original. These are a faithful redraw, not that file.
- On dark backgrounds, put the flame on a white circle (as in the website's link preview) rather than changing its colours.
